# 📽️ HE3AM Presentation

وب‌سایت فارسی ارائه کلاسی درس «ما هم می‌توانیم» از کتاب تفکر و سواد رسانه‌ای پایه دهم. این پروژه برای نمایش محتوای ارائه در مرورگر و اشتراک‌گذاری فایل‌های پاورپوینت ساخته شده است.

## هدف و امکانات

- صفحه ارائه با طراحی واکنش‌گرا و راست‌چین
- نمایش محتوای اسلایدها در سایت
- بخش اشتراک‌گذاری پاورپوینت
- آپلود فایل‌های PPTX در Supabase Storage
- نمایش فهرست فایل‌های بارگذاری‌شده و دریافت آن‌ها
- محدودیت حجم فایل و بررسی پسوند/نوع فایل در رابط کاربری

## فناوری‌ها

- HTML، CSS و JavaScript
- GitHub Pages برای میزبانی سایت
- Supabase Storage برای نگهداری فایل‌های PPTX

## تنظیمات Supabase

1. در Supabase یک پروژه ایجاد کنید.
2. مقدار **Project URL** و کلید عمومی **Publishable** (یا anon قدیمی) را از تنظیمات API بردارید.
3. این دو مقدار را در فایل `config.js` قرار دهید.
4. فایل `supabase-setup.sql` را در SQL Editor پروژه اجرا کنید.
5. مطمئن شوید Storage bucket با نام `presentations` ساخته شده و سیاست‌های لازم برای خواندن و آپلود برقرارند.
6. سایت را با `Ctrl + Shift + R` تازه‌سازی و یک فایل PPTX آزمایشی بارگذاری کنید.

> فقط کلید عمومی Publishable/anon برای کد مرورگر مناسب است. کلید Secret یا `service_role` را هرگز در `config.js` قرار ندهید.

## محدودیت‌های آپلود

- فرمت پشتیبانی‌شده: `.pptx`
- حداکثر حجم هر فایل: ۲۰ مگابایت
- دسترسی آپلود و مشاهده طبق سیاست فعلی Storage عمومی است؛ بنابراین بازدیدکنندگان می‌توانند فایل بارگذاری کنند و فایل‌های موجود را ببینند.
- برای استفاده عمومی گسترده، محدودسازی تعداد آپلودها و محافظت ضدسوءاستفاده مانند CAPTCHA پیشنهاد می‌شود.

## انتشار GitHub Pages

در تنظیمات مخزن، از **Settings → Pages** انتشار از شاخه `main` و پوشه ریشه (`/ (root)`) را انتخاب کنید.

**آدرس سایت:** https://he3amsvg.github.io/he3am-presentation/

## نکته درباره فایل ارائه

صفحه وب می‌تواند محتوای اسلایدها را به‌صورت HTML نمایش دهد و فایل‌های PPTX را جداگانه در بخش اشتراک‌گذاری فهرست کند. وجود فایل PPTX اصلی در مخزن یا نمایش مستقیم آن در اسلایدها، به بارگذاری و اتصال جداگانه همان فایل وابسته است.
