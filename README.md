# HE3AM Presentation

صفحه ارائه کلاسی درس «ما هم می‌توانیم» — تفکر و سواد رسانه‌ای پایه دهم.

## راه‌اندازی آپلود عمومی پاورپوینت

این سایت به Supabase Storage وصل می‌شود تا همه بازدیدکنندگان بتوانند فایل PPTX آپلود کنند و فایل‌های دیگران را ببینند و دریافت کنند.

1. در Supabase پروژه قبلی‌ات را باز کن.
2. از بخش **Project Settings → API**، مقدار **Project URL** و **Publishable key** (یا کلید قدیمی `anon`) را بردار.
3. فایل `config.js` را در همین مخزن باز کن و مقدارهای `YOUR_SUPABASE_PROJECT_URL` و `YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY` را با آن‌ها جایگزین کن. فقط کلید عمومی Publishable/anon مجاز است؛ هرگز `service_role` یا Secret key را در سایت قرار نده.
4. در Supabase به **SQL Editor** برو، محتوای فایل `supabase-setup.sql` را اجرا کن.
5. پس از انتشار GitHub Pages، بخش «اشتراک‌گذاری پاورپوینت» فعال می‌شود.

**محدودیت‌ها:** فقط PPTX و حداکثر ۲۰ مگابایت برای هر فایل. آپلود و مشاهده برای همه عمومی است. سیاست‌های فعلی اجازه حذف یا جایگزینی فایل‌ها را از طریق سایت نمی‌دهند.

> توجه: چون آپلود عمومی است، هر کسی می‌تواند فایل اضافه کند و ممکن است فضای ذخیره‌سازی با فایل‌های ناخواسته پر شود. برای استفاده عمومی گسترده، بهتر است بعداً CAPTCHA و محدودیت تعداد آپلود اضافه شود.

## انتشار GitHub Pages

از مسیر **Settings → Pages**، گزینه **Deploy from a branch** را انتخاب کن؛ Branch: `main` و Folder: `/ (root)` و سپس Save را بزن.
