# HE3AM Presentation

صفحه ارائه کلاسی درس «ما هم می‌توانیم» — تفکر و سواد رسانه‌ای پایه دهم.

## افزودن فایل پاورپوینت

فایل ارائه را با نام دقیق `presentation.pptx` در ریشه مخزن قرار دهید. پس از انتشار GitHub Pages، دکمه‌های دریافت و مشاهده آنلاین به‌صورت خودکار فعال می‌شوند.

## انتشار GitHub Pages

از مسیر **Settings → Pages**، گزینه **Deploy from a branch** را انتخاب کنید؛ Branch: `main` و Folder: `/ (root)` و سپس Save را بزنید.
